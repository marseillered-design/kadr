# Кадр

[English version](README.md)

Программа для снимков экрана для Windows, macOS и Linux в духе Lightshot — но вы сами выбираете, куда загружать снимки: в Catbox, Imgur или любой свой сервис.

**Открытый код** под [лицензией MIT](LICENSE) — меняйте что угодно: см. [Как настроить Кадр под себя](CUSTOMIZING.ru.md).

## Скачать

Установщик для вашей системы — на странице **Releases**:

| Система | Файл |
|---|---|
| Windows 10/11 | `Kadr-Setup-Windows.exe` (или `Kadr.exe` без установки) |
| macOS на Apple Silicon (M1–M4) | `Kadr-macOS-AppleSilicon.dmg` |
| macOS на Intel | `Kadr-macOS-Intel.dmg` |
| Ubuntu, Debian, Mint | `Kadr-Linux-amd64.deb` |
| Fedora, openSUSE | `Kadr-Linux-x86_64.rpm` |
| Любой Linux без установки | `Kadr-Linux-x86_64.AppImage` |

**Windows** — запустите установщик, пароль администратора не нужен. У Кадра нет платной цифровой подписи, поэтому при первом запуске Windows может показать «Система Windows защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**.

**macOS** — откройте .dmg и перетащите **Kadr** на папку **«Программы»**. Если в первый раз macOS не открывает его: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**. При первом снимке macOS попросит доступ к **Записи экрана**: включите Kadr и перезапустите его. Значок Кадра — в строке меню вверху.

**Linux** — дважды щёлкните .deb или .rpm и нажмите **«Установить»**; Кадр появится в меню приложений. В GNOME для значка в трее нужно расширение AppIndicator (в Ubuntu оно уже есть).

## Как пользоваться

- **Shift+PageUp** — выделить область (на Mac — **⌘⇧2**). Вы можете выбрать любую комбинацию клавиш в настройках. Окно под курсором подсвечивается: щелчок берёт его ровно по краям, щелчок по рабочему столу — весь экран. Лупа у курсора показывает пиксели, координаты и цвет.
- Инструменты справа: карандаш (P), линия (L), стрелка (A), прямоугольник (R), овал (E), маркер (M), текст (T), шаги 1-2-3 (N), пиксели (B) и размытие (U), чтобы скрыть личные данные, цвет, отмена (Ctrl+Z). Колёсико мыши меняет толщину и размер текста. С Shift — ровные линии и квадраты.
- Под выделением: **загрузить** (Ctrl+D) — стрелка рядом позволяет выбрать, куда загрузить; **копировать** (Ctrl+C или Enter); **сохранить** (Ctrl+S); **печать** (Ctrl+P); **закрыть** (Esc).
- **Запись видео:** **Shift+PageDown** (на Mac — **⌘⇧7**) — выделите область или щёлкните по окну, включите или выключите звук компьютера и микрофон, нажмите **Записать** (Enter). Рядом с областью появится маленькая панель: время, пауза, стоп и «удалить»; ни панель, ни красная рамка в видео не попадают. Повторное Shift+PageDown останавливает запись. MP4 (H.264 + AAC, кодирует встроенный в Windows кодек) сохраняется в папку «Видео» (на Mac — «Фильмы»), подпапка Kadr; из уведомления его можно открыть, показать в папке или загрузить. Кадры в секунду, папка и клавиши — Настройки → Запись видео. В Windows видео кодирует встроенный кодек Windows, в macOS и Linux — встроенный в Qt (MP4, или WebM, если в системе нет кодека H.264). macOS записывает звук компьютера начиная с macOS 13 и один раз спрашивает разрешение на микрофон. В Linux звук компьютера берётся из PulseAudio/PipeWire; в Wayland система в начале каждой записи спрашивает, какой экран показать.
- Выделение двигается мышью и стрелками (Shift+стрелки меняют размер), его углы и края можно тянуть.
- После загрузки ссылка уже в буфере обмена, а в углу экрана появляется уведомление: щелчок открывает ссылку, кнопка копирует её ещё раз.
- После сохранения (Ctrl+S) тоже появляется уведомление: щелчок открывает картинку, кнопка с папкой показывает её в Проводнике / Finder.
- Значок в трее / строке меню: снимок, загрузка картинки с диска или из буфера, выбор места загрузки, история загрузок (с удалением с Imgur), настройки.
- Языки: Русский, Українська, English, Deutsch, Français, Español, Italiano — Настройки → «Общее» → «Язык». Сначала Кадр берёт язык системы.
- Формат снимков для сохранения и загрузки: PNG или JPG с выбором качества.
- Прокси для загрузки: как в системе, без прокси или свой адрес с логином и паролем (пароль хранится зашифрованным).
- Уведомления об успехе можно выключить; ошибки показываются всегда.
- **Обновляется сам:** через минуту после запуска и потом каждые 6 часов Кадр проверяет GitHub Releases; новая версия скачивается, проверяется (SHA-256) и ставится, когда Кадр ничем не занят, затем он перезапускается. Выключается в настройках; «Проверить обновления» — в меню значка. (Пакеты .deb/.rpm на Linux просят пароль, поэтому ставятся по щелчку по уведомлению.)
- Windows: можно добавить «Кадр (загрузить)» в меню **«Отправить»** — правой кнопкой по картинке → Отправить → Кадр.

## Куда загружать

**Catbox** — работает сразу: без регистрации и ключей, ссылки вида `files.catbox.moe/abc123.png` не удаляются. Выбран по умолчанию.

**Imgur** — появится, когда в релиз будет встроен Client ID (или если вписать `ImgurClientId` в settings.json, см. [CUSTOMIZING.ru.md](CUSTOMIZING.ru.md)).

**ImgBB** — картинки до 32 МБ, ссылка ведёт прямо на картинку (`i.ibb.co/…`). Работает сразу: ключ встроен в релиз. Видео ImgBB не принимает.

**Свой сервис** — Настройки → «Свои сервисы для загрузки» → «Добавить…»: адрес, поле с файлом и где в ответе ссылка (`{json:data.url}`, `{response}`, `{regex:...}`). Готовые файлы ShareX `.sxcu` импортируются как есть.

## Сборка

Всё собирается на GitHub (`.github/workflows/build.yml`); тег `vX.Y.Z` выкладывает установщики на странице Releases.

- **Windows:** `powershell -ExecutionPolicy Bypass -File build.ps1` собирает `Kadr.exe` встроенным в Windows компилятором C# (.NET Framework 4.8) — ничего ставить не нужно. Установщик — `installer/windows/kadr.iss` (Inno Setup).
- **macOS и Linux:** версия на Qt в папке [qt](qt/README.md).
- **Иконка:** `qt/tools/draw_icon.py` рисует все размеры в `icons/`.

Настройки и история: Windows `%APPDATA%\Kadr`, macOS `~/Library/Application Support/Kadr`, Linux `~/.config/kadr`.
