**Kadr** — screenshots for Windows, macOS and Linux with drawing tools and upload to Catbox, Imgur or your own service.

**New in 1.4.2:** a proper Windows installer — language, welcome, licence, choose the folder, Start menu folder, shortcuts and autostart, finish with "Launch". Remote desktops (RDP, AnyDesk, TeamViewer, virtual machines…) now get the screenshot key while their window is in front, so the screenshot tool on the other computer reacts instead of Kadr (Settings → General).

**New in 1.4.1:** simpler Settings — no key fields any more; services that work without sign-up are listed instead (Imgur appears once it has a key).

**New in 1.4.0: ImgBB.** Upload screenshots to ImgBB (pictures up to 32 MB, direct links `i.ibb.co/…`): choose it under “Upload to” or with the ▾ arrow on the screenshot bar.

**New in 1.3.1:** the recording hotkey has its own on/off switch (Settings → Screen recording), separate from the screenshot hotkey.

**New: screen recording on Windows.** Shift+PageDown → select an area → Record. Computer sound and microphone (each can be switched off), pause, stop, discard; MP4 is saved to Videos\Kadr and can be uploaded from the notice. Installed copies update themselves.

| System | Download |
|---|---|
| Windows 10/11 | `Kadr-Setup-Windows.exe` (or `Kadr.exe`, no installation) |
| macOS, Apple Silicon (M1–M4) | `Kadr-macOS-AppleSilicon.dmg` |
| macOS, Intel | `Kadr-macOS-Intel.dmg` |
| Ubuntu, Debian, Mint | `Kadr-Linux-amd64.deb` |
| Fedora, openSUSE | `Kadr-Linux-x86_64.rpm` |
| Any Linux, no installation | `Kadr-Linux-x86_64.AppImage` |

**Shift+PageUp** (⌘⇧2 on a Mac) selects an area — you can choose any key combination you like in Settings.

First launch: Kadr has no paid code signature. On Windows click **More info → Run anyway**; on macOS open **System Settings → Privacy & Security → Open Anyway**, then allow **Screen Recording**.

Kadr updates itself to new releases (Settings → Update automatically).
